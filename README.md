# Mão Certa — Marketplace de Serviços

Landing page responsiva inspirada na identidade visual do material de divulgação do Mão Certa:
- Preto + amarelo como cores principais
- Profissionais verificados
- Categorias de serviços
- Busca por serviço e localização
- Cards de profissionais
- Fluxo "Encontre → Compare → Contrate"
- Área para cadastro de profissionais
- Modal de demonstração
- Filtros por categoria

## Como abrir

1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Para editar, use VS Code.

## Estrutura

- `index.html` — estrutura da página
- `css/style.css` — visual e responsividade
- `js/script.js` — filtros, busca e modais
- `assets/` — imagens e materiais

## Próxima etapa para transformar em marketplace real

1. Login/cadastro de cliente e profissional.
2. Banco de dados de usuários e serviços.
3. Busca real por cidade/categoria.
4. Página individual do profissional.
5. Fotos/portfólio.
6. Avaliações.
7. Solicitação de orçamento.
8. Chat ou contato.
9. Painel do profissional.
10. Backend com Firebase ou Supabase.
